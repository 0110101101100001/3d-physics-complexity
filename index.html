DETEÇÃO DE COLISÃO

CONTEXTO: Otimização de motores físicos para simulações 3D.

COMPLEXIDADE: Pior Caso: O(n²) (Verificação ingénua).

OP. BÁSICA: Teste de sobreposição AABB nos eixos X, Y e Z.

> FUNCAO intersectarAABB(A, B):
>   dx = abs(A.x - B.x)
>   dy = abs(A.y - B.y)
>   dz = abs(A.z - B.z)
>
>   SE dx < (A.size + B.size)/2
>    E dy < (A.size + B.size)/2
>    E dz < (A.size + B.size)/2:
>      RETORNAR VERDADEIRO
>   RETORNAR FALSO
_
01 // CONTEXTO

Contextualização do Problema

Otimização de motores físicos para videojogos e simulações 3D. Em cenários densos, testar colisões cegas consome rapidamente o CPU, tornando essencial métodos de rejeição rápida (Broad Phase).

02 // ALGORITMO

Descrição do Algoritmo

O algoritmo Axis-Aligned Bounding Box (AABB) delimita cada objeto com um cubo alinhado aos eixos. A colisão é detetada verificando simultaneamente a sobreposição de distâncias nos eixos X, Y e Z.

03 // MAPEAMENTO

Mapeamento de Operações

A operação básica é o teste lógico de sobreposição AABB. Para N objetos, numa abordagem de força bruta, a operação é executada para todos os pares possíveis na cena.

04 // PROVA MATEMÁTICA

Análise e Prova Matemática

• Melhor Caso (Ω): O(1) se otimizado com particionamento espacial.
• Pior Caso (O): O(n²). A contagem de verificações na matriz de N elementos é resolvida pela Progressão Aritmética: (N*(N-1))/2.
